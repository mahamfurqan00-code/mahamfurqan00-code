# 💫 About Me:
I am a final-year BS Software Engineering student at Virtual University of Pakistan with a strong interest in Python development, data analysis, web scraping, and workflow automation. I have hands-on experience with Python, Object-Oriented Programming (OOP), Pandas, BeautifulSoup, Git, GitHub, and Google AppSheet. My projects include a Bank Account Management System, Quote Scraper and Analyzer, Campus Store Sales Analytics, Lahore City Explorer, and a final-year project focused on detecting fraudulent apps using sentiment analysis (NLP). I am passionate about solving real-world problems, continuously improving my technical skills, and building practical software solutions. I am eager to explore new technologies, collaborate on meaningful projects, and grow as a software developer.
